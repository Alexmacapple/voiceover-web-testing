# VoiceOver Getting Started — OS X 10.8

Extrait du guide Apple (source : https://help.apple.com/voiceover/info/guide/10.8/English.lproj/index.html),
texte original en anglais, limité aux chapitres utiles au test web :
5 chapitres sur 13. Les chapitres sur
OS X, le texte, les apps, la collaboration, la personnalisation, le braille et
les gestes, ainsi que les options braille, trackpad, voix et sons, sont omis ;
un lien vers un sujet omis renvoie à la page Apple. Lecture par niveaux :
cet index (chapitres), puis le `README.md` de chaque chapitre (sujets), puis
un fichier par sujet. Les captures d’écran ne sont pas copiées : leur
texte alternatif est conservé. Les tableaux de commandes deviennent des
listes « action → commande ».

Attention : guide de 2012 (OS X 10.8). Les commandes de base restent
valides sur les macOS récents, mais certains noms d’interface, gestes et
réglages ont changé ; vérifier sur la version cible avant de s’y fier.
