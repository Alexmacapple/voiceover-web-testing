# Web Rotor pane of the Web category

Chapitre : [Appendix B. VoiceOver Utility Options](README.md) · [Index](../index.md)

Use the Web Rotor pane of the Web category to specify which items to include, and in what order, in the Web rotor.

*Format : Option → Description*

- Item Order → **The list of items you can include in the Web rotor. Select a checkbox to include an item in the rotor; deselect a checkbox to exclude an item from the rotor. You can reorder items in the list so the items you use most will appear first in the rotor.**
