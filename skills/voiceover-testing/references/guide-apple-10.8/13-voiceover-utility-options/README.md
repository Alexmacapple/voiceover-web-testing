# Appendix B. VoiceOver Utility Options

[Retour à l’index](../index.md)

This chapter lists the options on each VoiceOver Utility pane and explains how to use the options.

## Sujets

- [General category](general-category.md) : Use the General category to specify a login greeting, use portable preferences, and enable AppleScript scripts to control VoiceOver.
- [Speech pane of the Verbosity category](speech-pane-of-the-verbosity-category.md) : Use the Speech pane of the Verbosity category to specify the default verbosity level (amount of information you want to receive) and a verbosity level for specific controls—such as apps, checkboxes,…
- [Text pane of the Verbosity category](text-pane-of-the-verbosity-category.md) : Use the Text pane of the Verbosity category to customize the amount of punctuation, text, and text attributes you hear, among other options.
- [Announcements pane of the Verbosity category](announcements-pane-of-the-verbosity-category.md) : Use the Announcements pane of the Verbosity category to specify when you want VoiceOver to announce certain events, such as when a modifier key is pressed, and when to speak certain text, such as lab…
- [Hints pane of the Verbosity category](hints-pane-of-the-verbosity-category.md) : Use the Hints pane to have VoiceOver provide more information about the item in the VoiceOver cursor.
- [Navigation category](navigation-category.md) : Use the Navigation category to customize navigation settings, such as those related to using the VoiceOver cursor, automatically interacting with items, and fast searching.
- [Navigation pane of the Web category](navigation-pane-of-the-web-category.md) : Use the Navigation pane of the Web category to set options related to navigating and browsing webpages.
- [Page Loading pane of the Web category](page-loading-pane-of-the-web-category.md) : Use the Page Loading pane of the Web category to specify what you want to happen while a new webpage is being displayed.
- [Web Rotor pane of the Web category](web-rotor-pane-of-the-web-category.md) : Use the Web Rotor pane of the Web category to specify which items to include, and in what order, in the Web rotor.
- [VoiceOver Cursor pane of the Visuals category](voiceover-cursor-pane-of-the-visuals-category.md) : Use the VoiceOver Cursor pane of the Visuals category to set options related to the VoiceOver cursor.
- [Caption Panel pane of the Visuals category](caption-panel-pane-of-the-visuals-category.md) : Use the Caption Panel pane of the Visuals category to customize the size and appearance of the caption panel.
- [Quick Nav pane of the Commanders category](quick-nav-pane-of-the-commanders-category.md) : Use the Quick Nav pane to enable and set options for using Quick Nav, and to assign VoiceOver commands to single keys (instead of key combinations) for navigating webpages using Quick Nav.
- [Activities category](activities-category.md) : Use the Activities category to set up activities and customize VoiceOver settings for specific uses.
