# VoiceOver Cursor pane of the Visuals category

Chapitre : [Appendix B. VoiceOver Utility Options](README.md) · [Index](../index.md)

Use the VoiceOver Cursor pane of the Visuals category to set options related to the VoiceOver cursor.

*Format : Option → Description*

- Show VoiceOver cursor → **Select the checkbox to show the VoiceOver cursor (the default setting). The VoiceOver cursor appears as a dark outlined box.**
- VoiceOver Cursor Magnification → **Drag the slider toward Small or Large to decrease or increase the size of the VoiceOver cursor.**
- When reading text, move VoiceOver cursor by → **From the pop-up menu, choose how the VoiceOver cursor should move while reading: Sentence or Word.**
