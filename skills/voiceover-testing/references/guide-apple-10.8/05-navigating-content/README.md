# Chapter 5. Navigating Content

[Retour à l’index](../index.md)

VoiceOver provides numerous ways to navigate content and text. In this chapter, you’ll learn how to navigate content such as tables and text, and how to use navigation features such as Quick Nav, the Item Chooser, and hot spots, among others.

## Sujets

- [Navigate menus](navigate-menus.md) : The menu bar at the top of the screen contains these areas: the Apple and app menus, status menus, the Spotlight menu, and the Notification Center icon.
- [Navigate tables](navigate-tables.md) : You can navigate tables in text areas by row and column, and sort by column.
- [Navigate by finding text or letters](navigate-by-finding-text-or-letters.md) : You can navigate by searching for specific text or a specific letter.
- [Navigate using text attributes](navigate-using-text-attributes.md) : You can navigate in a document by searching for text attributes, such as a bold font or a change in font color.
- [Navigate using cursor wrapping](navigate-using-cursor-wrapping.md) : When you use cursor wrapping, VoiceOver treats the items in a window or column as a continuous loop.
- [Navigate using the Tab key](navigate-using-the-tab-key.md) : OS X includes full keyboard access, which lets you use the Tab and arrow keys to move the keyboard focus to text boxes, lists, radio buttons, checkboxes, and other controls.
- [Navigate using Quick Nav](navigate-using-quick-nav.md) : With Quick Nav, you can navigate webpages and apps using only the arrow keys, and navigate webpages using single keys.
- [Navigate using the Item Chooser](navigate-using-the-item-chooser.md) : You can use the Item Chooser to quickly go to any item on the screen or in a window.
- [Monitor items with hot spots](monitor-items-with-hot-spots.md) : You can use hot spots to monitor items and jump to those items at any time.
