# About keyboard shortcuts and VoiceOver

Chapitre : [Chapter 1. Introducing VoiceOver](README.md) · [Index](../index.md)

Apps use key combinations as shortcuts to help you work faster. Many shortcuts are common to all OS X apps, such as Command-S for Save and Command-P for Print. You can use these keyboard shortcuts and VoiceOver commands as one way to control actions on your Mac. VoiceOver commands always include the VO keys (the Control and Option keys).

When you use VoiceOver to navigate menus, you hear the keyboard shortcut, if one exists, after the name of the menu command. For example, in the File menu, “New, Command N” means that you can use the keyboard shortcut Command-N to create a new file.
