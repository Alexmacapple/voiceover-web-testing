# Navigate webpages using frames

Chapitre : [Chapter 6. Browsing the Internet](README.md) · [Index](../index.md)

Some webpages organize information into separate areas called “frames.” Sometimes one frame contains links that update the contents of other frames on the page. You may find it easier to navigate these webpages using frames.

- To move to the next frame, press VO-Command-F.

- To move to the previous frame, press VO-Command-Shift-F.

- If frames are listed in the Web rotor, you can use the rotor to move to a specific frame.

  [Navigate webpages using the Web rotor](navigate-webpages-using-the-web-rotor.md)

If frames are listed in the Web rotor, you can listen to the webpage summary to hear how many frames are on the current webpage.

[Hear a summary of a webpage](hear-a-summary-of-a-webpage.md)
