# New and changed VoiceOver commands in OS X Mountain Lion

Chapitre : [Appendix A. Commands and Gestures](README.md) · [Index](../index.md)

VoiceOver in OS X Mountain Lion (version 10.8) introduces several new and changed commands.

**Note:** If your keyboard has an Fn key, press it when you press a function key.

#### New and changed VoiceOver commands in Mac OS X Lion

*Format : Action → Command*

**New**

- Double-click the mouse → **VO-Shift-Space bar-Space bar**
- Hear the position of a window and whether anything overlaps it → **VO-Command-F2-F2**

**Changed**

- Close a window (in addition to close the selected desktop in Mission Control) → **VO-Command-Escape**
- Hear the dimensions of a window and the section of the screen where it’s located → **VO-Command-F2**
- Hear the dimensions of an item and the section of the screen where it’s located → **VO-Command-F3**
- Hear the position of an item and whether anything overlaps it → **VO-Command-F3-F3**
- Jump to the sort button in a column header in a table → **VO-\|**
